# Athar (أثر)

> "Und Wir schreiben auf, was sie vorausgeschickt haben und ihre Spuren
> (Atharahum)." — Surah Ya-Sin (36:12)

**Athar** = die Spur, der Fußabdruck, das bleibende Vermächtnis.

Zu 100% kostenlose, werbefreie, datenschutzfreundliche islamische Plattform
(Web, Android, iOS) + öffentliche API für Entwickler — als **Sadaqah
Jariyah** (fortwährende wohltätige Tat) konzipiert und komplett Open Source.

## Kampagne: "Leave your Athar"

Positionierung für Open-Source-Contributors: Code beisteuern als bleibende
gute Tat. Zielgruppe: Entwickler, die Sadaqah Jariyah durch Code statt durch
Spende hinterlassen wollen. Kein kommerzielles Produkt, kein Tracking, keine
Werbung — das ist der Differenzierungspunkt gegenüber Muslim Pro, Athan Pro,
AlMosaly etc.
