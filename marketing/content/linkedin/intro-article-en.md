# Athar — the code that outlives its authors

## 1. Code outlives its authors

Software written in the nineties still runs today. Its authors are long gone, their names appear nowhere. The code keeps working.

I spent years building systems like that. Code written by engineers I never met, running every day without anyone noticing. They left. Their work stayed.

That scene kept asking me one question: what remains of our code and our work when we leave?

## 2. The human behind the code

Today, AI tools write thousands of lines in seconds. But the machine produces silent code: no intention, no reason for building. What makes the difference is the human standing behind the idea.

That's where Athar (أثر) came from.

## 3. What Athar is

Athar is not another tech platform. It's a project built to leave a useful trace, from the verse: «وَنَكْتُبُ مَا قَدَّمُوا وَآثَارَهُمْ» — "And We record what they have put forth and what they left behind (their athar)." (Surah Ya-Sin 36:12)

In Islamic tradition, a Sadaqah Jariyah is a charity that keeps paying out after you're gone. A well you dug. A book you wrote. Code you wrote that still runs. This platform is built in that frame: free, ad-free, no tracking, no selling of data, for anyone who wants to pray on time anywhere.

Products built to last stand on clear principles:

1. **100% free.** No ads, no tracking, no trading in people's data.
2. **Open source.** Owned by everyone, code and idea.
3. **A public API.** So any developer can build on it without starting from zero.

Athar is the reminder that the real trace is made by the human.

## 4. The covenant

I won't accept growth at the expense of value. Between more users and the purity of the promise, I choose the promise, every time. This is not a commercial project. It is a Sadaqah Jariyah, my technological trace.

## 5. The conclusion

If you're building something you hope will run stronger and longer than your own existence, start today. One idea is enough. The trace stays.

We are building in the open. The code repositories open at MVP launch.
